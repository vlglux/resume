## Word Swipe

**Тип проекта:** Pet-проект  
**Роль:** разработчик  
**Технологии:** HTML, CSS, Vanilla JavaScript  
**Публикация:** GitHub Pages

Веб-приложение для изучения английской лексики с использованием интерактивных карточек.

Приложение позволяет создавать собственные колоды слов, изучать карточки и распределять слова в зависимости от уровня их знания.

### Реализованный функционал

- Создание пользовательских колод и карточек.
- Интерактивный переворот карточек.
- Модульная архитектура с использованием ES Modules.
- Свайпы для распределения слов по уровню знания.
- Поддержка мышиных и сенсорных событий.
- Мобильное взаимодействие.
- Повторение сложных слов.
- Добавление отдельных слов и списков в избранное.
- Сохранение состояния приложения и пользовательских данных в localStorage.
- Адаптивная мобильная версия.

Приложение опубликовано на GitHub Pages и используется автором и другими пользователями.

Этот документ является источником фактической информации для сайта-резюме.

При работе с ним необходимо соблюдать следующие правила:

1. Не добавлять выдуманные места работы, проекты, технологии, обязанности и достижения.
2. Не менять даты работы и обучения.
3. Не исключать значимые проекты и коммерческий опыт.
4. Не смешивать разные места работы в одну позицию.
5. Допускается сокращать и редактировать формулировки для улучшения читаемости, сохраняя исходный смысл.
6. Допускается менять порядок представления информации для лучшей визуальной структуры.
7. Word Swipe следует выделить как основной собственный проект.
8. Frontend-разработку следует позиционировать как основное направление профессионального развития.
9. SEO, CMS и маркетинговый опыт также важны и должны быть представлены как дополнительные профессиональные компетенции.
10. Если для сайта требуются ссылки на проекты, фотографии или другие материалы, которых нет в этом документе, не создавать фиктивные URL. Оставить понятное место для последующего добавления.

**Главная задача сайта:** представить кандидата как специалиста с практическим опытом разработки коммерческих сайтов, знаниями frontend-технологий и собственным JavaScript-проектом.
